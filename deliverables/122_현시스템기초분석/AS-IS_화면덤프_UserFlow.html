4. AS-IS User Flow

4-1. 진입 모델 (채널별)

PC 32 vs MWEB 6 — PC는 GNB에 전 영역을 평면 노출하고, MWEB은 전체메뉴(MAM) 단일 허브를 경유한다. MWEB 평균 depth가 1.24 더 깊은 구조적 원인.

4-2. T3 문화센터 수강신청 — 의도 vs 실제

구분경로
정상 경로강좌찾기 → 신청 → S1 → S2 → S3 → 수강내역
우회 경로장바구니 경유(별도 화면 PCU1.1.5.4, depth 7)
막다른 길정원 초과 → 대기신청 레이어에서 종료(수강 인원 초과 대기신청L). 대기 상태 조회 화면 [확인필요]
되돌아옴S1에서 나의회원이 없으면 나의회원추가L로 나갔다 복귀 — 결제 흐름 중 회원등록이 끼어든다
실제 클릭 동선·이탈 지점은 [확인필요] — 등급 C에서는 문서상 연결만 확인 가능. 214 이용로그가 확보되면 이 흐름의 실제 이탈률로 검증할 것(현재 로그 미확보).
