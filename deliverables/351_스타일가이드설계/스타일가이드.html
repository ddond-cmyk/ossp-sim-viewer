1. 이 가이드의 지위 — 무엇을 확정하고 무엇을 미루는가

334(시안디자인)가 시안 3안(A 정보 우선 · B 지점의 얼굴 · C 거래 신뢰)을 냈고 채택은 고객사 게이트 몫이다. 시안이 안 닫혔는데 스타일가이드를 지금 쓰는 이유 —

토큰의 「이름·구조·역할」과 「값」은 확정 시점이 다르다. 어떤 안이 채택돼도 ①색이 역할로 불리고 ②타이포가 스케일로 잡히고 ③간격이 배수로 움직인다는 구조는 안 바뀐다. 바뀌는 건 값이다.

층이 문서(v0.1)시안 확정 후(v1.0)
토큰 이름·계층✅ 확정불변
역할 배정(어디에 무엇을 쓰나)✅ 확정불변
값(hex·px)[가정값] — 개발 착수용교체
이렇게 갈라 두면 423(UI개발퍼블리싱)이 시안을 기다리지 않고 착수할 수 있다 — 값 교체는 CSS 변수 파일 1개 수정이다.

2. 확정 입력 (변형 3안 공통)

입력지위
해피니스 산스 (그룹 전용서체)✅ 확정 — P-BRD-01 대체 제안 불가. 타이포 실험 대상 아님
더현대 로고타입 국/영문✅ 확정 — P-BRD-02 가이드 준수
그룹 UI/UX 가이드라인구간별 채택 — 333(UI가이드정의) §1 판정 상속. 설계기준 5원칙 채택, 사이드바 전제 불채택
컨셉키워드 시각 제약 4건334(시안디자인) §2 — 반복이 견디는 절제가 1차 기준
브랜드 컬러 팔레트⛔ 미확보 — 332(컨텐츠가이드설계)와 같은 상황(브랜드 표기 0/5). 색 가정값의 근거가 없음을 명시

3. 토큰 아키텍처 — 3층

① 원시(primitive)   gray-0…gray-900 · green-500 · red-500 …   값만 있고 용도 없음
② 의미(semantic)    --hd-ink · --hd-bg · --hd-line · --hd-state-error …   용도만 있고 화면 모름
③ 컴포넌트(component) --hd-btn-primary-bg · --hd-card-radius …   ②를 참조. 직접 값 금지

규칙 3개

  1. 화면·컴포넌트 CSS는 ③만 쓴다. ①을 직접 쓰는 순간 시안 교체가 전수 수정이 된다.
  2. 네이밍: --hd-{범주}-{역할}[-{상태}]. 케밥 케이스, 프로젝트 접두 hd 고정.
  3. 지점 accent는 토큰이 아니라 데이터다 — §6.

4. 색 — 역할 체계 (값은 [가정값])

토큰역할가정값근거
--hd-ink본문 텍스트#1A1A1A순흑 대신 — 대비 확보하되 반복 피로 완화
--hd-ink-muted보조 텍스트#767676대비 4.5:1 하한 — 354(접근성가이드설계) 연동
--hd-bg / --hd-bg-alt바탕 / 구획#FFFFFF / #F7F7F7컨셉키워드 K2 「반복이 견디는 절제」 — 뼈대는 무채색
--hd-line / --hd-line-strong구분선 / 표 헤더#E4E4E4 / #C8C8C8
--hd-brand브랜드 강조[가정값 #0B4A3C]⛔ 팔레트 미확보 — 유일하게 근거 없는 값. 시안 게이트 1순위 교체 대상
--hd-state-error오류·실패#B3261E332(컨텐츠가이드설계) §6 예외 문구와 짝 — 문구·색이 한 컴포넌트(T-05)
--hd-state-success완료#1A7F37거래 완료 화면
--hd-state-info안내#1A5FB4빈 상태·대안 제시(T-04)
--hd-focus포커스 링#1A5FB4키보드 초점 — 354(접근성가이드설계) 필수 항목

상태색 사용 규칙: 상태색은 상태에만 쓴다. 장식·강조에 오류색을 쓰는 순간 컨셉키워드 K4(막혔을 때 갈 곳)의 신호 체계가 무너진다.

5. 타이포·간격·그리드

타이포 스케일 — 해피니스 산스 단일 서체. 굵기 2단(400/700)만 사용(웹폰트 용량).

토큰rem용도
--hd-t-display2.0허브 타이틀
--hd-t-title1.5화면 제목(h1)
--hd-t-section1.17절 제목 · 카드 제목
--hd-t-body1.0 (=16px)본문 — 최소 크기. 이보다 작은 본문 금지
--hd-t-caption0.875메타·라벨 — 본문 외 보조만

간격 — 4px 배수 단일 축: --hd-sp-1…8 = 4·8·12·16·24·32·48·64. 임의 px 금지.

그리드 — 331(와이어프레임설계) 12칼럼 상속. 브레이크포인트 2단: ≥1024px PC / <1024px MWEB. 중간 단계는 콘텐츠가 요구할 때만 추가(331(와이어프레임설계) 한계 5 인정).

6. 지점 accent — 컨셉키워드 K2의 스타일 구현

지점 16개가 같은 템플릿을 쓴다. 지점 개성은 스타일시트가 아니라 데이터로 들어온다.

.hd-store { --hd-store-accent: var(--hd-brand); }  /* 기본값 */
/* Admin이 지점별로 --hd-store-accent 1개 값만 주입 — 지점당 CSS 1줄 */
허용금지
지점 대표 비주얼 · accent 1색 · 특성 모듈 콘텐츠지점별 레이아웃 변경 · 지점별 서체 · accent 2색 이상
지점이 바꿀 수 있는 것을 1개로 제한하는 것이 「한 번 만들고 지점마다 붙인다」의 스타일 번역이다. 열어두면 16개 지점이 16개 사이트가 된다.

7. 컴포넌트 토큰 슬롯 — 343(설계리뷰및리팩토링) 매핑표 연동

유형 골격 ↔ 컴포넌트 매핑표의 20종에 토큰 슬롯을 배정했다. 대표 3종만 수록 — 전량은 423(UI개발퍼블리싱) tokens.css가 SSOT.

컴포넌트슬롯
C-01 버튼(주요/보조/취소)--hd-btn-{kind}-bg/ink/line — 주요=ink 면, 보조=선, 취소=텍스트
T-05 예외 안내--hd-state-error + --hd-bg-alt — 문구는 332(컨텐츠가이드설계) §6 사전값, 색은 여기
N-02 컨텍스트 바--hd-store-accent 유일 사용처(§6) + --hd-bg-alt
