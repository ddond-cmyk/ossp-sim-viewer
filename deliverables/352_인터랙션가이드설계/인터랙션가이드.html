1. 입력 어휘 — 342(UI상세설계) §1-2 승계·확정

원천 스토리보드 계보는 네이티브 앱이라 제스처 8종을 쓴다. 이 프로젝트는 웹이므로 어휘를 채널별로 고정한다. 디스크립션·개발·QA가 같은 단어를 쓰기 위한 사전이다.

채널허용금지 · 이유
PC선택 · Hover · 입력 · 스크롤우클릭 의존 — 브라우저 기본과 충돌
MWEBTap · 스와이프(배너·탭 한정) · 스크롤Long Tap·Pinch — 모바일 웹 신뢰 불가 · 가로 전체 스와이프 — 브라우저 뒤로가기와 충돌
공통{조건} 충족 시 · {값} 초과 시—

Hover 원칙: Hover는 가산적이다 — Hover가 없으면(터치) 접근 불가한 정보·기능 금지. GNB 2Depth 드롭다운은 Hover로 열리되 선택(클릭)으로도 열린다.

2. 컴포넌트 상태 5종 — 전 인터랙티브 요소 공통

상태시각규칙
Default351(스타일가이드설계) 컴포넌트 토큰
Hover (PC만)배경 1단 변화터치에서 미정의 — sticky hover 금지
Focus--hd-focus 2px 링전 요소 필수 · 제거 금지 — 354(접근성가이드설계) 1급
Active눌림 표현100ms 내 즉시
Disabled명도 저하 + cursor:default비활성 사유를 인접 텍스트로 — 색만으로 전달 금지

실행 버튼 계약 (342(UI상세설계) 프로세스형 문형의 인터랙션 번역): Default 비활성 → 필수값·유효성 충족 시 활성 → 선택 시 이중 제출 방지 잠금 + 진행 표시.

3. 오버레이(T-07) 계약 — 공통 모듈 3종이 이 위에 선다

343(설계리뷰및리팩토링) §4가 정의한 본인인증·주소검색·약관 상세가 전부 이 계약을 상속한다.

항목규칙
열림배경 딤 + 배경 조작 차단. 배경 스크롤 잠금
닫힘 3경로닫기 버튼 · ESC(PC) · 딤 영역 선택. 셋 다 제공
닫힘 시 값명시적 완료(선택·동의·인증)만 반환 — 닫기·ESC·딤은 반환 없음, 호출 화면 기존 값 유지
포커스열림 시 오버레이 첫 요소로 이동 · 포커스 트랩 · 닫힘 시 호출 요소로 복귀
중첩금지. 오버레이 안에서 오버레이가 필요하면 내부 전환(본인인증 수단 전환처럼)으로
이력MWEB 뒤로가기 = 오버레이 닫기 (화면 이탈 아님)

4. 폼 · 검증 타이밍 — 342(UI상세설계) 밸리데이션 규칙의 시점 확정

시점무엇
입력 중형식 제한만(자릿수 차단·문자종 필터). 오류 문구는 아직 안 띄운다 — 쓰는 중에 혼내지 않는다
필드 이탈(blur)1차 검증 — 해당 필드 오류 문구 노출(332(컨텐츠가이드설계) §4-2 3요소 공식)
제출 선택2차 전체 검증 — 첫 오류 필드로 포커스+스크롤 이동
실패 응답T-05 예외 골격 — 입력값 보존(332(컨텐츠가이드설계) "신청 내용은 그대로 있습니다"가 참이 되는 조건)
